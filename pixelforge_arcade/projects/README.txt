Bundled Studio arcade projects. Regenerate with go run ./cmd/pixelforge-arcade-projects.
These opt-in project presets use Go game rules, an authored 20x11 tile layout and
an initial-frame sprite for the editor. The same project runs in native Studio,
the shared native player and the browser. Studio can open/save these projects,
but the current scene workspace does not graphically edit preset maps or rules.
