Controls and Studio project

Arrows or WASD hop. Wait for safe gaps before crossing. P pauses and R restarts. Touch buttons support held input.

This project runs through the same Go runtime in Studio and WebAssembly. Extract the project download, open game.pforge in the updated Studio and press F5. These are code-driven presets. The current scene workspace does not graphically edit their maps or rules.

New game presets are silent. Snake and Pac-Man retain their sound controls.
